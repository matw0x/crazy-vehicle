# Test Case Specification: «Топот»

Версия 0.1, до независимого ревью и заморозки. Источник требований - SPEC.md.
20 TC: 16 module (80%), 4 scenario (20%). Один TC соответствует одному тест-методу. Варианты входов внутри TC проверяются через subTest либо последовательные проверки одного правила. В именах методов дефис ID заменён подчёркиванием: TC-01 → test_TC_01_… .

Базовый самолёт: name="Топот", mass_kg=1000, leg_length_m=2, max_speed_kmh=20, energy=100; позиция 0, ноги целы. Если не указано иное, используется это состояние. Каждый отказ сохраняет всё состояние. Погрешность числовых сравнений - 1e-7.
